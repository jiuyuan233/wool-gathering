## 🧱 技术框架

| 层 | 技术 | 说明 |
|----|------|------|
| 语言 | Python 3.11 | 所有收集 / 生成脚本，标准库 + `requests` |
| CI/CD | GitHub Actions | 6 时段 cron 定时触发（避开整点），零服务器 |
| 抓取 | 关键词规则解析 | 博客/V2EX/Reddit/ITAD/itch.io + 云厂商页 + Epic/Steam/GOG 官方 API，不依赖 AI |
| 浏览器渲染 | Playwright（Chromium） | 仅小黑盒 SPA（打折帖/社区帖）需要，未安装时自动跳过 |
| AI | OpenAI 兼容中转站 | 主力 ChatAnywhere `gpt-6.1-sol`，备用 SiliconFlow `deepseek-ai/DeepSeek-V3.2` 自动切换；仅处理 PENDING_URLS 自然语言条目 |
| 数据存储 | JSON 文件 | `data/*/activities.json`，无数据库，git 即版本控制 |
| 去重 | 稳定 ID（标题+URL 哈希） | 旧值优先合并，防止覆盖已确认字段；已归档 id 拒绝回流 |
| 可视化 | SVG 甘特图 | `docs/calendar.svg`，零前端依赖，README 直接 `<img>` 渲染 |
| 归档 | 按月归档 | 过期活动写 `docs/archive/YYYY-MM.md`，索引 `index.json` 幂等 |
| 部署 | 零部署 | 不依赖 GitHub Pages，README 嵌 SVG 即是展示位（`docs/index.html` 为可选网页版） |

**设计理念**：抓取链路全靠确定性规则（稳定、免费、可复盘），AI 只做规则搞不定的自然语言理解。
GitHub 仓库本身即数据库 + CI + 展示位。fork 后配 1 个 Secret（`AI_API_KEY`）就能跑。
