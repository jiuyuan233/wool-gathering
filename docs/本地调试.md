## 💻 本地调试

### 最安全的方式：只跑整理（不抓网络）

```bash
git clone https://github.com/<你的用户名>/wool-gathering.git
cd wool-gathering
pip install -r scripts/requirements.txt

# Linux / macOS
export GITHUB_REPOSITORY="<你的用户名>/wool-gathering"
python scripts/collect.py finalize

# Windows PowerShell
$env:GITHUB_REPOSITORY = "<你的用户名>/wool-gathering"
python scripts/collect.py finalize
```

`finalize` 只读本地数据生成 SVG + README + 前端 JSON + 归档过期活动，**不会抓网络、不需要 AI Key**。
跑完 `data/`、`docs/calendar.svg`、`docs/data/`、`README.md` 会刷新。

> 注意：`GITHUB_REPOSITORY` 不设的话，`docs/data/meta.json` 的 `repository` 字段会变空字符串。
> 本地调试的产物改动不要直接 commit（见下）。

### 抓真实数据（会访问外部网站）

```bash
python scripts/collect.py ai             # 云厂商 + 博客聚合
python scripts/collect.py games          # Epic/Steam/GOG API + 博客聚合
python scripts/collect.py drive          # V2EX 开车线报
python scripts/collect.py all            # 全部 + finalize（约 5-20 分钟）
```

抓取是关键词规则解析，不需要 AI Key。只有当 `PENDING_URLS.md` 里有自然语言条目时才调 AI，
那时才需要：

```bash
export AI_BASE_URL="https://api.chatanywhere.tech/v1"
export AI_API_KEY="sk-xxx"          # 可选，不配则自然语言条目记录处理失败
export AI_MODEL="gpt-6.1-sol"       # 可选，默认即此值
```

### 验证结果

```bash
ls docs/archive/                 # 过期活动归档（index.json + 各月 .md）
grep "已归档" README.md          # 统计区的归档计数
python -c "import json; print(json.load(open('docs/data/meta.json')))"
```

### 小黑盒抓取（可选）

小黑盒是 SPA，需要浏览器渲染：

```bash
pip install playwright
playwright install chromium
python scripts/collect.py game-discount
```

没装 Playwright 时相关抓取会自动跳过并告警，不影响其他板块。

### 调试纪律（来自 AGENT.md 第 11 节）

本地跑出来的 `data/` `docs/` `README.md` 改动**不要 commit**（调试完
`git checkout -- README.md docs/ data/` 丢弃），让 Actions 自己在云上跑。
只有改了 `scripts/` 规则或文档才需要提交。
