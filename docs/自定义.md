## 🛠 自定义

### 添加/调整日常轮询源（重要：先分清两类源）

**日常真正在抓的源**有三处，改哪要看你想加什么：

| 源类型 | 在哪加 | 适合收录 |
|--------|--------|---------|
| 博客/聚合站/V2EX | `scripts/blog_collector.py` 顶部的 `SOURCES` 字典，按分类加一条 | 有文章列表的静态页/RSS/JSON API |
| 云厂商活动页 | `scripts/cloud_collector.py` 的 `CLOUD_PAGES` | 华为云/阿里云/腾讯云等 |
| 小黑盒帖/社区 | `data/sources.json` 加一条 `type: heybox` 或 `heybox-community` | 小黑盒分享帖（Playwright 渲染） |

`blog_collector.SOURCES` 的一条示例（`parser` 决定解析方式，通用博客用 `parse_blog_articles`）：

```python
{"name": "某博客", "url": "https://example.com/blog", "parser": "generic"},
```

> `data/sources.json` 里的 `html` 类型源**只做登记**（用户提交 URL 的去重凭证），
> 不参与日常轮询——想让某个网站每天被查，要加到上面三处之一。
> 想临时抓某个 URL 一次：写进 `PENDING_URLS.md`，finalize 会当场抓取入库。

### 调整 AI 抽取规则

编辑 `scripts/prompts.py` 里的 `SYSTEM_PROMPT`（AI 只用于 PENDING_URLS 自然语言条目）。
人可读版教程在 `scripts/ai_guide.md`。

### 修改运行时间

编辑 `.github/workflows/daily-collect.yml` 的 6 个 cron 表达式（UTC 时间，北京时间 = UTC + 8）。
当前值：

```yaml
schedule:
  - cron: "17 21 * * *"   # 05:17 北京 → ai-cloud（云厂商）
  - cron: "23 0 * * *"    # 08:23 北京 → ai-blog（博客聚合）
  - cron: "41 2 * * *"    # 10:41 北京 → drive（V2EX 开车线报）
  - cron: "37 5 * * *"    # 13:37 北京 → games-direct（Epic/Steam/GOG 官方 API）
  - cron: "53 7 * * *"    # 15:53 北京 → games-blog,game-discount（博客聚合 + 小黑盒）
  - cron: "47 10 * * *"   # 18:47 北京 → finalize（PENDING_URLS + 归档 + SVG + README）
```

> 6 个时段分散全天、避开整点，减轻免费源网站压力。改分钟数即可错峰。

### 修改分类归属 / 颜色

- README 分区：`scripts/calendar_generator.py` 的 `FREE_CATS` / `DISCOUNT_CATS`
- SVG 分区顺序与颜色：`scripts/svg_calendar.py` 的 `CAT_ORDER_SVG` / `COLOR_*`
- 开车线报车型子分类：`scripts/calendar_generator.py` 的 `CAR_TYPES`

改完跑 `python scripts/collect.py finalize` 重新生成产物（见 [本地调试](本地调试.md)）。
