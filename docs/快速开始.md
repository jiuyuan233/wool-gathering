## 🚀 快速开始（2 步跑通）

### 第 1 步：配置 AI API Key Secrets

workflow 已默认配置 **ChatAnywhere `gpt-6.1-sol` 为主力 + SiliconFlow DeepSeek-V3.2 为备用**
（在 `.github/workflows/daily-collect.yml` 的 env 里），需要配 **2 个 Secret**：

进入仓库 **Settings → Secrets and variables → Actions → New repository secret**：

| Secret 名 | Value | 说明 |
|-----------|-------|------|
| `AI_API_KEY` | ChatAnywhere API Key（形如 `sk-xxx`，去 [chatanywhere](https://chatanywhere.top) 注册免费领取） | 主力 |
| `AI_FALLBACK_API_KEY` | SiliconFlow API Key（[siliconflow.cn](https://siliconflow.cn) 注册领取，或留空不配） | 备用，主力连续 3 次失败时自动切换 |

> 配了几个 Secret 就生效几个：只配 `AI_API_KEY` 也能跑（只是没有备用兜底）。
>
> **额度说明**：AI 只在处理 `PENDING_URLS.md` 里的自然语言条目时才被调用，日常运行
> 消耗为 0；ChatAnywhere 免费版每周 50000 点 + 每天 100 次请求完全够用。

**想换模型？** 编辑 workflow 的 env 改 `AI_BASE_URL` / `AI_MODEL`（任意 OpenAI 协议兼容的都行），
改完不用配别的。当前该 key 实测可用的 19 个模型清单见 [AGENT.md 13.1.1](../AGENT.md)。

### 第 2 步：手动触发首次运行

进入 **Actions → Daily Collect → Run workflow** → Mode 留 `all` → 等绿勾出现（全量约 5-20 分钟）

完成后：
- README 顶部的 **活动时间轴** SVG 自动更新（你正在看的就是）
- [docs/分类活动.md](分类活动.md) 列出全部在收活动
- `data/*/activities.json` 是结构化原始数据
- 已过期的活动会自动归档到 `docs/archive/`，不会出现在 README 里

之后每天分 **6 个时段** 自动运行（分散全天、避开整点，减轻免费源网站压力），无需干预：

| 北京时间 | 模式 | 做什么 |
|---------|------|-------|
| 05:17 | `ai-cloud` | 云厂商活动（华为云/阿里云/腾讯云） |
| 08:23 | `ai-blog` | 博客聚合（AI 板块，含开源工具分流） |
| 11:41 | `drive` | V2EX 开车线报 |
| 13:37 | `games-direct` | Epic/Steam/GOG 官方 API |
| 15:53 | `games-blog,game-discount` | ITAD/itch.io/Reddit + 小黑盒（Playwright） |
| 18:47 | `finalize` | 处理 PENDING_URLS + 归档过期活动 + 生成 SVG/README |

> ℹ️ 本仓库的日历直接以 SVG 图片形式嵌在 README 里渲染，**不需要** GitHub Pages；
> `docs/index.html` 是一个可选的网页版界面（读 `docs/data/*.json`），想用再开 Pages。
