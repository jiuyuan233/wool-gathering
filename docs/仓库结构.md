## 📁 仓库结构

```
wool-gathering/
├── AGENT.md                       # 维护规范（21 节，给开发/维护 AI 或人看的操作文档）
├── DEV_GUIDE.md                   # 开发交接文档（架构、AI 工作流、遗留问题）
├── CHANGELOG.md                   # 更新日志
├── PENDING_URLS.md                # 用户提交新网址/自然语言的入口（AI 自动处理）
├── README.md                      # 仓库主页（脚本生成，别手改）
├── .github/workflows/
│   └── daily-collect.yml          # Actions：六时段定时任务 + 自动提交
├── data/                          # 数据目录（脚本写，人别手改 activities.json）
│   ├── sources.json               # 源登记表：heybox 类参与日常轮询，html 类为登记
│   ├── ai/activities.json         # AI/云服务优惠
│   ├── open-source/activities.json# 开源免费工具（长期免费，end_date 空）
│   ├── drive/activities.json      # 开车线报
│   ├── games/activities.json      # 游戏喜加一
│   ├── shopping/activities.json   # 购物优惠
│   ├── video-vip/activities.json  # 视频会员
│   ├── netdisk-vip/activities.json# 网盘会员
│   └── game-discount/activities.json # 游戏打折（小黑盒）
├── scripts/                       # Python 收集脚本
│   ├── collect.py                 # 主入口（Action 调用；含 PENDING_URLS 处理 + 过期归档）
│   ├── blog_collector.py          # 内置博客/V2EX/Reddit/ITAD/itch.io 源 + 分类规则 + 小黑盒
│   ├── cloud_collector.py         # 云厂商活动抓取（华为云/阿里云/腾讯云/腾讯 WorkBuddy）
│   ├── direct_collector.py        # Epic/Steam/GOG 官方 API 抓取
│   ├── ai_client.py               # AI 客户端（OpenAI 兼容，主力+备用自动切换）
│   ├── prompts.py                 # AI 提示词（SYSTEM_PROMPT，含游戏标题中文译名规则）
│   ├── ai_guide.md                # AI 使用教程（人可读）
│   ├── sources_manager.py         # sources.json 的读取/抓取工具类
│   ├── dedup.py                   # 规范化 + 去重合并 + 状态刷新
│   ├── calendar_generator.py      # README + 前端数据生成（含车型子分类、ended 过滤）
│   ├── svg_calendar.py            # SVG 甘特图日历生成（含文字防重叠）
│   ├── readme_template.md         # README 模板（含 {{占位符}}）
│   ├── utils.py                   # 工具函数（日期/ID/状态/JSON 读写）
│   └── requirements.txt
└── docs/                          # 产物 + 文档
    ├── calendar.svg               # README 嵌入的甘特图（自动生成）
    ├── 分类活动.md                # 全部活动详情表（自动生成）
    ├── archive/                   # 过期活动按月归档（自动生成，index.json 为索引）
    ├── data/                      # 前端数据 activities.json + meta.json（自动生成）
    ├── index.html / js/ / css/    # 可选网页版界面（读 docs/data/*.json）
    ├── 日常更新指南.md            # ⭐ 日常更新 AI / 新手的操作手册
    ├── 快速开始.md / Fork指南.md / 工作原理.md / 技术框架.md
    ├── 仓库结构.md / 数据结构.md / 日历视图.md / AI提示词.md
    ├── 自定义.md / 本地调试.md / 常见问题.md / GAME_PLATFORMS.md / License.md
    └── _config.yml                # Pages 配置（禁用 Jekyll）
```
